# Robo Cross

Аналог Crossy Road от RENT ROBOT: робот бежит через неоновый мегаполис будущего. Статический сайт (GitHub Pages), запускается как Telegram Mini App.

## Что внутри

- Пять районов со своим видом, музыкой и дальним горизонтом: Даунтаун, Нео-Токио, Эко-квартал, Промзона, Неон-порт
- Дороги, ховер-трассы, маглев с переездом, каналы с катерами, буйками и разводными мостами, провалы с грави-платформами
- Ловушки: лазерные заграждения, сканеры, энергопанели, патрульные дроны, стройка с краном и падающими балками
- Парки, живые пешеходы (дают «пять», фанаты, курьеры), смена дня и ночи, дождь
- Процедурная музыка и звук, вся графика рисуется кодом
- Пауза, автопауза при сворачивании, сохранение забега (продолжение после закрытия бота)

## Файлы

- `index.html`, `style.css`: страница и интерфейс
- `js/game.js`: игровая логика, генератор уровня, камера, ввод, пауза и сохранение
- `js/models.js`: воксельные модели
- `js/textures.js`: процедурные текстуры, вывески, логотип
- `js/env.js`, `js/backdrop.js`: районы, время суток, погода, дальний горизонт
- `js/npc.js`: пешеходы
- `js/audio.js`: звуки и музыка
- `js/telegram.js`: интеграция с Telegram (вибрация, CloudStorage, события сворачивания)
- `assets/`: логотип RENT ROBOT; сюда же можно положить `robot.glb` (модель робота)

## Локальный запуск

```bash
python -m http.server 8080
```

Открыть http://localhost:8080. Управление: стрелки / WASD, пауза Esc или P. На телефоне тап и свайпы.

С `?debug` в адресе в консоли доступны `rc.night()`, `rc.day()`, `rc.rain()`, `rc.jump(80)`, `rc.god = true`.

## Модель робота

Положить `assets/robot.glb` (Y вверх, лицом к -Z). Узлы `LegL`, `LegR`, `ArmL`, `ArmR` будут анимироваться. Поворот правится в `ROBOT_ROT_Y` в `js/game.js`.

## GitHub Pages и Telegram

1. Settings → Pages → Deploy from a branch → `main`, `/ (root)`.
2. В @BotFather: `/newapp` (или Bot Settings → Menu Button) с URL `https://<логин>.github.io/ROBOCROSS/`.
